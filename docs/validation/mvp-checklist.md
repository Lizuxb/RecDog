# 风险验证 MVP：实施与验收清单

日期：2026-11-02。以下全部未执行。依据：[开发计划](../development-plan.md)、[技术方案](../technical-design-v1.md)。

## 执行规则与证据

先建立独立探针；通过后再决定哪些代码可纳入正式模块。不直接把一次短演示当作长时性能结论。当前不安装 SDK/模型、不上传任何真实录音，不采集用户声音。

每次验证记录：日期、提交号、OS 版本、CPU/内存、依赖/模型/服务版本、配置、脱敏样本编号、执行命令/操作、预期、实际、指标、证据路径、通过/失败及替代方案。原始录音/模板放仓库外；只提交不含个人信息的结论、指标和截图。新报告命名为 `YYYY-MM-DD-主题.md`。

## M0：验证环境

- [ ] 在目标 Windows 机器安装 .NET 10 SDK，记录官方支持与实际版本。
- [ ] 执行 README 的 restore/build/run，窗口正常启动；另在干净检出构建。
- [ ] 准备脱敏 DOCX 样本：段落、表格、合并单元格、内容控件、页眉页脚、页码、页边距、跨页表格；另备普通话清晰/噪声/重叠讲话音频及人工校对文本。
- [ ] 分开准备 8GB 基础功能机与 16GB 本机转写机，记录实际硬件；可为同一机器不同实验配置，但必须注明。

## M1：编辑器与真实模板

实施：WPF RichTextBox/FlowDocument 最小探针，Open XML SDK 导入到内部节点后编辑，再导出 DOCX。稳定节点 ID 独立于视图元素；不使用 WPF 对象做持久格式。

- [ ] 完成中文输入法、光标/录音目标分离、普通段落和表格填写、基本撤销。
- [ ] 表格合并/拆分/删除与节点关联可解释，未知对象不会静默丢失，兼容报告列出不支持项。
- [ ] 导出的 DOCX 在 Word/WPS 打开，对比正文、表格结构、主要字体和页面设置；保留可接受变化样例，不要求逐像素分页一致。
- [ ] 用十万汉字/数百表格行压力样本滚动、输入、两秒保存；在 1137×827 与常见窗口检查滚动至末尾和工具栏可达性。

门槛：真实模板可完成主要填写和导出；输入响应 P95 暂以 100ms 为候选基线，记录实际值。达不到时先评估编辑适配/分块或替代编辑器，不直接承诺整篇 FlowDocument 可行。

## M2：音频归档与独立进程

实施：NAudio/WASAPI 采集、AudioHost 进程与 FFmpeg 持续 MP3 编码；只为归档和必要状态提供接口，采集不等待转写。先短样本排错，再分别长测。

- [ ] 麦克风、系统声音、混合模式短测，包括静音再恢复、暂停继续、结束再录。
- [ ] 检查暂停不采集、同次继续同一录音；结束后再录新 ID/文件；中文/空格路径可用。
- [ ] 持续至少四小时，期间编辑并保存；音频可解码、时长/时间轴正确，无意外截断或明显漂移，按预先选定参考音源记录误差。
- [ ] 记录每分钟内存/CPU、队列深度、写盘与音频时长；对比一/二/四小时趋势，确认音频不整段积存在内存。
- [ ] 测设备移除、编码器退出和主程序退出：停止采集、尽力收尾已录音频、明确报错，不偷偷后台录音。

门槛：录音完整、内存不随时长线性无界增长；故障不破坏上一份录音。混录时钟或共享读边界失败时先修复/调整编码策略。

## M3：中文转写与保护规则

实施：先选一个 sherpa-onnx 中文流式组合与一个在线候选实测，记录能力；whisper.cpp 只在有必要比较录后方案时加入。服务密钥在会话内使用，在线测试需用户明确选择测试音频。

- [ ] 对人工校对样本测 CER、RTF、终稿延迟、时间戳和内存；分别记录清晰、噪声、重叠样本，不合成一个掩盖差异的平均值。
- [ ] 本机 RTF<1 且持续运行有资源余量才标“可实时”；未通过标为录后模式或更换模型。准确率样本和结果需用户评审后确定支持组合，不自行捏造统一 CER 合格线。
- [ ] 使用假事件源验证：A 时讲话、切 B 后首次返回写 B；切 C 后旧片段修正留 B；人工编辑不被覆盖；重复/乱序/跨会话事件不重复追加。
- [ ] 删除目标后进未分配区；重设目标不自动补入；主动插入只执行一次。
- [ ] 在线断网/恢复、模型加载失败/进程退出：录音与编辑继续；补转历史先进入未分配区，不自动切服务或上传。

门槛：规则用例全部通过；首个转写组合有真实效果数据与适用条件。供应商不能可靠区分新增/修正时保留待处理结果，不猜测覆盖。

## M4：保存与迁移

实施：真实 SQLite 项目目录，单写入协调与事务；文档节点、转写与来源一致提交，附件完整写入后再发布引用。音频不存数据库 BLOB，不每两秒重打包历史录音。

- [ ] 连续输入超过两秒仍周期保存；保存过程中继续输入，保存状态不误报已清空修改。
- [ ] 关闭/重开与复制已关闭项目到新路径后，已保存内容和来源一致；重开不自动开始录音。
- [ ] 录音中确认快照，后续输入和转写只改变草稿，快照保持原样。
- [ ] 注入写失败/导出失败/中断：不破坏上次已保存状态、不发布半文件，提供重试；不承诺恢复未保存内容。
- [ ] 模型不存在或密钥不可用时仍可查看、编辑和导出既有内容。

门槛：保存与来源一致，复制不依赖旧绝对路径；记录保存 P50/P95、失败/积压和磁盘峰值。

## M5：组合验收与下一阶段决定

- [ ] 同时运行录音、转写、长文档编辑和周期保存至少四小时，复查 M1—M4 指标。
- [ ] 明确 Windows/设备、编辑器、编码器、模型和服务支持范围，以及未通过项。
- [ ] 所有关键失败均有调整方案和复测记录；复测前不宣称阶段 1 通过。
- [ ] 用户评审真实模板效果与转写质量，确认技术路线后进入项目基础与可试用闭环。
